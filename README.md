# TactiX — Tactical Swarm Intelligence

**A swarm of specialist AI agents that turns synthetic football events into explainable match intelligence.**

Built for the **Microsoft × Premier League "Inside the Game" Developer Hackathon 2026**.
Target category: **Best Multi-Agent System**.

---

## The problem

Every broadcast can already tell you *what* happened: 62% possession, 14 shots, a goal in the 71st minute. Almost none of them tell you *why it mattered*.

A possession figure without context explains nothing. A goal without history is just a number on a scoreboard. The story of a match lives in the relationships between events — a pattern that repeats, a weakness that keeps being exploited, a substitution that flips the rhythm of the game.

## What TactiX does

TactiX ingests a live stream of synthetic match events and runs them through a team of specialist agents that **disagree, hand off to each other, and build on each other's findings** to produce something no single pass over the data can: an explanation.

The difference on screen:

> **Typical output:** "Goal by Hartley, 62'."
>
> **TactiX:** "Goal by Hartley, 62'. His third of the season from the left channel, and the fourth consecutive match where Ashford conceded after losing the ball in midfield — the same pattern that decided the Northbridge fixture."

That second sentence is only possible because one agent computed the event, another recognised the season-long pattern, and a third decided it was worth telling you about.

## Architecture

TactiX is built in four layers. Each one is independently testable, and the lower layers run without any language model at all.

### Layer 1 — Synthetic Universe

A generator that creates an entire fictional league, not just a single match:

- Fictional clubs with squads, formations and player attribute profiles
- A season history of previously played fixtures
- Form streaks, per-player tendencies and head-to-head records

This is what gives the agents something to reason *against*. A match with no history has no narrative.

All data is **synthetic and generated by this project**. No real players, clubs, branding or match data is used anywhere.

### Layer 2 — Deterministic Metrics Engine

All football statistics are computed in plain code, never by a model:

- Possession sequences, pass networks, final-third entries
- Pressure events, turnovers, transition windows
- Momentum and rhythm indicators derived from event density

Agents **interpret** numbers that have already been calculated. They never invent a count. This keeps the output verifiable and makes every claim traceable back to the events that produced it.

### Layer 3 — The Agent Swarm

Five specialists coordinated through an explicit workflow on **Microsoft Agent Framework**:

| Agent | Role | Depends on |
|---|---|---|
| **Tactical Analyst** | Patterns, pressure shifts, momentum | Metrics |
| **Historian** | Cross-references live events against season history and player profiles | Metrics + Universe |
| **Narrator** | Play-by-play commentary and match recap | Analyst + Historian |
| **Personalizer** | Adapts output by club, player, language and viewer profile | Narrator |
| **Orchestrator** | Coordinates the workflow, reconciles contradictions, handles partial failures | All |

The dependency chain is the point. The Historian → Narrator handoff is what makes the narration *contextual* rather than descriptive — a single agent holding one prompt cannot produce it, because the historical lookup and the narrative framing are different jobs with different evidence.

When agents disagree, the Orchestrator surfaces the disagreement rather than hiding it. When one fails, the report ships partial and says so.

### Layer 4 — Personalized Experience

The same match intelligence, rendered two genuinely different ways:

- **Analyst mode** — dense metrics, pattern timelines, evidence you can drill into
- **Fan mode** — narrative, key moments, why they mattered

Plus language selection, favourite club and single-player focus modes, so the same engine serves a data-hungry analyst and a casual viewer without either getting the other's experience.

## Scope and limitations

- All data is synthetic. TactiX makes no claims about real players, clubs or matches, and uses no real match footage or data.
- Tactical readings are interpretations of generated events, not professional analysis.
- Agents state when the available evidence is insufficient rather than filling the gap with a confident guess.
